2. 🚀 STARTING THE PLATFORM LOCALLY
--------------------------------------------------------------------------------

### OPTION A: One-Click Scripts (Recommended for Local Dev)
# Linux / macOS / Git Bash:
./start.sh

# Windows (Command Prompt):
start.bat

# Windows (PowerShell):
.\start.ps1


### OPTION B: Full-Stack Docker Compose (Containerized Production Build)
# Start all services with live build:
docker compose up --build

# Start in detached background mode:
docker compose up -d --build

# View live container logs:
docker compose logs -f

# View backend logs only:
docker compose logs -f backend

# Stop all containers:
docker compose down


### OPTION C: Manual Startup (Separate Terminals)
# Terminal 1 — Backend:
cd backend
source venv/bin/activate    # On Windows: venv\Scripts\activate
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2 — Frontend:
cd frontend
npm run dev                 # Launches on http://localhost:5173

### 🅰️ BACKEND ON RENDER (Web Service - Handles API + WebSockets):
1. Create a new "Web Service" on dashboard.render.com connected to your GitHub repo.
2. Settings:
   - Root Directory:  backend
   - Runtime:         Python 3
   - Build Command:   pip install -r requirements.txt
   - Start Command:   uvicorn app.main:app --host 0.0.0.0 --port $PORT
   - Health Check:    /health
3. Environment Variables on Render:
   - DATABASE_URL:    postgresql://... (Supabase pooler URL from backend/.env)
   - SECRET_KEY:      krishiconnect-secret-key-2026-hackathon-demo
   - ALGORITHM:       HS256
   - ALLOWED_ORIGINS: *
   - OPERATOR_REG_SECRET: krishi-admin-2026
4. Reseeding Database on Render:
   - Go to Render Dashboard -> backend Web Service -> Shell
   - Run: python -m app.seed --reset

### 🅱️ FRONTEND ON VERCEL (Vite SPA on Global CDN):
1. Import repository on vercel.com.
2. Configure Project Settings:
   - Framework Preset: Vite
   - Root Directory:   frontend
   - Build Command:    npm run build
   - Output Directory: dist
3. Environment Variables on Vercel:
   - VITE_API_URL:    https://<your-backend-name>.onrender.com
   - VITE_WS_URL:     wss://<your-backend-name>.onrender.com
4. Click Deploy. `frontend/vercel.json` automatically handles SPA routing.

6. 🛠️ TROUBLESHOOTING & PORT KILLERS
--------------------------------------------------------------------------------

# Check if ports 8000 or 5173 are already occupied:
lsof -i :8000
lsof -i :5173

# Kill processes holding port 8000 or 5173 (if previous runs got orphaned):
kill -9 $(lsof -t -i:8000) 2>/dev/null || true
kill -9 $(lsof -t -i:5173) 2>/dev/null || true

# Test backend health endpoint directly:
curl -s http://localhost:8000/health

# Clean Docker containers and volumes (Deep Reset):
docker compose down -v --remove-orphans
